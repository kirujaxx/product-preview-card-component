# Product Preview Card Component

![Product Preview](./design/desktop-preview.jpg)

## Overview

This project is a solution to the **Product Preview Card Component** challenge on [Frontend Mentor](https://www.frontendmentor.io). The goal is to build a responsive product preview card that matches the provided design as closely as possible.

## Features

- **Responsive Design**: Optimized for both mobile and desktop views.
- **Interactive States**: Includes hover and focus states for interactive elements.

## Tools and Technologies

- **HTML5**: For semantic structure.
- **CSS3**: For styling and layout.
- **GitHub Pages**: For deployment.

## Getting Started

To view the project locally:

1. Clone the repository:
    ```bash
    git clone https://github.com/your-username/product-preview-card-component.git
    ```
2. Navigate to the project folder:
    ```bash
    cd product-preview-card-component
    ```
3. Open `index.html` in your browser.

## Design

The design files include both desktop and mobile layouts in JPG format. Use your best judgment for styles like `font-size`, `padding`, and `margin`.
